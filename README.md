# Navigating the Dusty Mysteries of the Universe

Website of the IFPU focus week *"Navigating the Dusty Mysteries of the Universe: from early epochs to cosmic noon"*, Trieste, 1–5 March 2027.

Served with GitHub Pages from the `main` branch: plain HTML/CSS/JS, no build step.

## Where things are

| File | What it contains |
|---|---|
| `data.js` | **Content that changes often**: organizers (their emails are the site's contacts), participants, abstract deadline and form link, program. Empty values appear on the site as "to be announced". |
| `index.html` | Page structure and fixed text (rationale, topics, format, logistics). |
| `style.css` | Look and feel. Colours are sampled from the poster and defined at the top. |
| `script.js` | Fills the page from `data.js`; no need to touch it. |
| `images/` | `scene.svg` (vector illustration taken from the poster), `poster.png` (full poster at 2520×3564, downloadable) and `poster-og.jpg` (link preview image). |
